  1. F-Droid 앱 실행
  2. 설정 → 저장소 → 저장소 추가
  3. 위 주소를 붙여넣고 추가
  4. KJournal 검색 후 설치

딥링크: fdroidrepos://__FDROID_REPO_HOST__?fingerprint=__FDROID_FINGERPRINT_URI__

지문 형식 주의: 딥링크에는 소문자·콜론 없이 넣어야 합니다. (F-Droid 앱 표시용은 위 콜론 형식)

설치 방법 (APK 직접 설치)

  • 위 APK 를 내려받습니다.
  • 브라우저/파일 앱에서 APK 를 열고 출처를 알 수 없는 앱 설치 허용을 켭니다.
  • 설치 후 앱을 실행합니다.
  • 타임라인 알림을 쓰려면 안내에 따라 알림 권한을 허용합니다.

기존에 다른 키로 서명된 버전이 설치되어 있으면 삭제 후 설치해야 합니다.

__VERSION__ 변경 사항

  • 캘린더 등 날짜 표기를 한국어로 수정 (AUGUST 2026 → 2026년 8월)
  • 영문으로 남아 있던 UI 문구 한국어 번역 (색상 선택, 보관, 복사, 장기, 시작까지, 키보드, 제거, 복용량, 탭 등)
  • 알림을 켤 때 앱이 종료되던 문제 수정 (Android 14+ 포그라운드 서비스 권한)
  • 타임라인 "지금" 표시 중 발생하던 오류 수정
  • 알림이 켜진 직후 꺼지던 문제 수정
  • 알림 버튼 토글 동작 추가 (다시 누르면 꺼짐)
  • 알림 상태에 따라 버튼 아이콘 변경 (▶ / ■)
  • 알림은 기본 접힘(접힘에서는 그래프 없음), 펼치면 왜곡 없이 표시
