저장소 주소 열기

주소__FDROID_REPO_URL__
지문(SHA-256)__FDROID_FINGERPRINT__
  1. F-Droid 앱 실행
  2. 설정 → 저장소 → 저장소 추가
  3. 위 주소를 붙여넣고 추가
  4. KJournal 검색 후 설치

딥링크: fdroidrepos://__FDROID_REPO_HOST__?fingerprint=__FDROID_FINGERPRINT_URI__
딥링크 지문은 소문자·콜론 없이 넣어야 합니다.

Install

설치 방법 (APK 직접 설치)

  • 위에서 APK 를 내려받습니다.
  • 브라우저/파일 앱에서 APK 를 열고 출처를 알 수 없는 앱 설치 허용을 켭니다.
  • 설치 후 앱을 실행합니다.
  • 타임라인 알림을 쓰려면 안내에 따라 알림 권한을 허용합니다.

기존에 다른 키로 서명된 버전(PB6 이하)이 설치되어 있으면 삭제 후 설치해야 합니다. PB7 → PB8 업데이트는 그대로 설치됩니다.
